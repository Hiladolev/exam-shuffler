# Add Answer Choice Button Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add a per-question "Add answer choice" button to the clean-questions review screen in `app.py`, so a missing choice (buried in garbled OCR question text) can be added back in manually.

**Architecture:** The clean-question loop already renders directly off `st.session_state["shuffled_questions"][i]["choices"]` (via a live `q` reference into that list). A button click appends an empty string to that list and calls `st.rerun()`, so the next render shows one more `st.text_input` with a fresh, empty, independently-editable key — no new session-state structure needed.

**Tech Stack:** Python, Streamlit — no new dependencies.

**Spec:** `docs/superpowers/specs/2026-07-26-add-answer-choice-design.md`

### Task 1: Add the "Add answer choice" button to the clean-question loop

- [ ] **Step 1: Add the button and its handler**

In `app.py`, change (currently lines 106-112):

        choices = []

            choice_text = st.text_input(
                f"Choice {j}", value=choice, key=f"clean_q_{i}_choice_{j}"
            )

to:

```python
        choices = []
        for j, choice in enumerate(q["choices"]):
            choice_text = st.text_input(
                f"Choice {j}", value=choice, key=f"clean_q_{i}_choice_{j}"
            )
            choices.append(choice_text)
        if st.button("Add answer choice", key=f"clean_q_{i}_add_choice"):
            q["choices"].append("")
            st.rerun()
        st.caption(f"Correct answer index: {q['correct_index']}")
```
